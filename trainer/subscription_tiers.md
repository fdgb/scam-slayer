# Scam Slayer 订阅档位与计费配置（P2 · 诚实标注）

> 本文件定义付费档位与计费口径，**仅供 SkillHub / SkillPay 上架与机构报价参考**。
> 实际收费由平台侧（SkillPay 按次 / SkillHub 付费下载）处理，本地 Skill 不含支付逻辑。
> 所有数字均为**规划口径**，与 `Scam_Slayer_BP.md` §5.4「0 收入现状」一致，非已成交价。

---

## 一、免费版（引流，永久免费）
- 对话式 on-demand 鉴别（五段式分级）：链接 / 图片 / 描述 / 账号
- 适老化卡片 + 子女转发文案（手动）
- 浏览器扩展 on-demand 边刷边鉴
- 每日案例库自动扩充（非监控）

## 二、付费点 A：B 端「责任转移 + 批量权限」
| 档位 | 适用 | 规划计费（SkillPay/年费） | 含能力 |
|------|------|---------------------------|--------|
| 试用 | 单机构验证 | 免费 14 天 / 限额调用 | monitor 模块 + batch 接口 + 合规报告 |
| 标准 | 社区/街道/养老机构 | 3,000–8,000 元/年 | 上述 + API 网关(api_server) + 批量权限(API Key) |
| 企业 | 内容平台/连锁机构 | 8,000–30,000 元/年 | 上述 + 高并发配额 + 定制合规报告模板 + 优先支持 |

- **责任转移落点**：合规报告(`compliance_report_*.md`)提供逐条追溯 + 责任兜底声明，机构可据此证明「已履行合理提醒义务」。
- **计费触发**：按调用量（规划 0.05–0.2 元/次）或年费；由 SkillPay 按次扣费，不预收款。

## 三、付费点 B：2C「替身守护」会员
| 档位 | 适用 | 规划计费 |
|------|------|----------|
| 基础 | 单子女守护单父母 | 免费（引流，限 3 个盯防项） |
| 守护 | 持续守护 | 19–99 元/月（**事件驱动转化**：本人/家人「差点被骗」后意愿最强） |
| 多亲 | 守护多位家人 | 99–199 元/月 |

- **诚实边界**：2C 持续订阅意愿弱，靠「差点被骗」事件触发，**不写稳定月费收入**（BP §5.5 红线）。
- 父母侧零操作；告警推送 + 远程看板(markdown; Web 看板在 scam-slayer-web，待开发)。

## 四、付费点 C/D（参考 BP §5.5）
- C：Skill 付费下载 9.9–29.9 元（SkillHub）
- D：定制化交付 5,000–50,000 元/项目（社区反诈看板 / 企业内容安全）
